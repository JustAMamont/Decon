# Decon

**Десктопный трекер практики деконцентрации внимания (дКВ) и психонетики.**

Rust + Dioxus. Offline-first, локальная SQLite-база, ноль конфигурационных файлов,
шифрование чувствительных данных. Linux и Windows, позже Android и веб-сервис
для сообщества практикующих.

## Что это

Готовых решений под психонетику нет: медитационные трекеры измеряют концентрацию
(«минуты на подушке»), а прогресс в дКВ — это равномерность распределения внимания,
осознаваемый фон, переключения между слоями (перцептивный → витальный →
семантический). Decon закрывает этот пробел:

- **Журнал сессий** с pre/post замерами по шкалам (см. [SCALES.md](docs/SCALES.md))
  и event-логом срывов/вспышек с таймкодами;
- **Зонды дня** (ESM): случайные срезы состояния в повседневности — там, где
  живёт настоящий эффект практики;
- **Тренажёры как измерительные приборы**: таблицы Шульте (3 режима), MOT —
  multiple object tracking, layer-switch drill; их метрики пишутся в общий
  журнал и коррелируют с самоотчётами;
- **Аналитика n-of-1**: тренды по слоям отдельно, корреляции с условиями
  (сон, время суток, кофеин), сравнение периодов;
- **Конструктор шкал**: своя феноменология, версионирование, без смешивания
  трендов между версиями.

## Принципы

1. Легковесность: минимум аллокаций в hot paths, бюджеты памяти, бенчмарки
   criterion как доказательство (см. [CONVENTIONS.md](docs/CONVENTIONS.md)).
2. Тесты и бенчмарки обязательны: unit + integration + property-based.
3. Документация обновляется в том же PR, что и код.
4. Скоупы и статус — в [ROADMAP.md](docs/ROADMAP.md).
5. Секреты не попадают в репозиторий (локальный gitleaks-скан перед каждым
   пушем; полный CI — на границах скоупов).
6. Ноль конфигов для пользователя: все настройки в БД, UI-редактирование;
   чувствительные поля шифруются (fernet, ключ — argon2id, хранение в OS keyring).
7. Строгая структура: workspace из трёх крейтов, модель — папка, модуль — файл.

## Стек

- **Rust** (edition 2024) — весь код, без JS/TS.
- **Dioxus 0.7** — UI: desktop (Linux/Windows) сейчас, Android и web —
  позже, тот же кодбазис.
- **SQLite** (rusqlite) — локальное хранение, миграции, WAL.
- **fernet + argon2 + keyring** — шифрование чувствительных полей.
- **criterion + proptest + assert_cmd** — бенчмарки и тесты.
